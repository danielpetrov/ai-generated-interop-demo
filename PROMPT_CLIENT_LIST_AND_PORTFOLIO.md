# Prompt: Generate Client Demo Apps

This document contains the prompt to generate the Client List and Client Portfolio demo applications.

## The Prompt

Copy the following into your AI assistant:

```markdown
Create two interop.io connected apps:
1. **Client List** - Displays a searchable list of clients.
2. **Client Portfolio** - Shows details for the selected client.
```
The user can prepend the message below to the prompt if they are not already included in the setup of the environment such as Codex / Claude Code or Antigravity:

## Additional Instructions

**Context Loading:**
If your environment (e.g., Codex, Claude Code, Antigravity) does not automatically load the agent configuration, prepend the following to your prompt:
